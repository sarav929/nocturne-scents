# Nocturne Scents (E-Commerce Website - CodeSpace)

A full-stack e-commerce website for a niche perfume retailer, built with PHP, MySQL, HTML, and CSS. Nocturne Scents offers a seamless shopping experience with user authentication, dynamic product filtering, and an intuitive admin panel for inventory management.

### Features:
- **User Authentication** – Secure login, logout, and account creation with password hashing for enhanced security.
- **Custom Form Validation** – User-friendly validation with detailed error messages to guide users.
- **Admin Panel** – Manage shop inventory with options to add, update, and remove products directly from the database.
- **Dynamic Shop Page** – Filter products by type or brand and sort by name, brand, or price for a tailored shopping experience.
- **Product Pages** – Individual product listings with detailed descriptions, fragrance notes, and categories.
- **Shopping Cart** – Add items, adjust quantities, and proceed through a streamlined checkout process.
- **Order History** – Users can view and track past purchases in the "My Orders" section.

### Technologies:
- **Frontend**: Bootstrap for responsive design, enhanced with custom CSS and media queries.
- **Backend**: PHP for server-side logic and data handling.
- **Database**: MySQL for efficient product, user, and order management.
- **Interactivity**: JavaScript for modals and dynamic page elements.
- **Testing**: Cypress.io for automated testing of core functionalities like login/logout, navigation, and cart management.
